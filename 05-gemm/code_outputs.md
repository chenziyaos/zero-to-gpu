## 占用率分析 (H100, Block 256 threads)

基于 H100 的更新规格：
- SM 最多驻留 64 warps（Hopper 架构升级，V100 为 32）
- 每个 warp = 32 线程
- Block 256 线程 = 8 warps

**注**：低占用率（12.5% - 25%）在 GEMM 中是正常的，因为指令级并行（ILP）充分，累加器驻留寄存器导致占用率必然降低。关键是隐藏访存延迟，而非简单追求占用率。

12. 极端情况处理
